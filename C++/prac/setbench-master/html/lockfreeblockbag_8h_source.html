19 // lock free bag that operates on elements of the block<T> type,
20 // defined in blockbag.h. this class does NOT allocate or deallocate any memory.
21 // instead, it simply chains blocks together using their next pointers.
22 // the implementation is a stack, with push and pop at the head.
23 // the aba problem is avoided using version numbers with a double-wide CAS.
24 // any contention issues with using a simple stack and overhead issues with
25 // double-wide CAS are unimportant, because operations on this bag only happen
26 // once a process has filled up two blocks of objects and needs to hand one
27 // off. thus, the number of operations on this class is several orders of
28 // magnitude smaller than the number of operations on the binary search tree.
